Возрождение функционала оригинального VTLite, всё делается через ИИ, за работоспособность не ручаюсь, установка сугубо на ваш страх и риск. Возможно мод перерастёт во что-то большее...

## VTLite Reborn — CP205

Последняя проверенная на реальном устройстве сборка: **CP205**, Android `versionCode 4850`, идентификатор приложения `com.vtosters.reborn`.

По результатам пользовательского тестирования на **RedMagic 8S Pro / Android 15**:

- Вход в аккаунт по логину и паролю без восстановления из файла.
- Авторизация сохранилась после закрытия и повторного открытия приложения.
- Личные переписки открываются.
- Отправка текстовых сообщений и медиа работает.

**Ограничения:** опыт одного устройства и аккаунта не доказывает стабильную авторизацию у всех пользователей. Причина прежней серверной ошибки `BRUTEFORCE_LOCK` не установлена; редкие ошибки загрузки фотографий при интенсивных сериях также ещё исследуются. Совместимость с Android 16 проверялась на уровне подписи APK, а не полным пользовательским тестом CP205.

Подробности и контрольная сумма: [описание CP205](releases/CP205.md).

## Как установить

1. Откройте [Releases](https://github.com/Ahaozpj/VTLite-Reborn/releases) и выберите нужную версию.
2. В разделе **Assets** скачайте файл с расширением `.apk`, а не исходный ZIP.
3. По возможности проверьте SHA-256 скачанного APK по значению в описании выпуска.
4. Установите APK штатными средствами Android. Если Android сообщает о несовместимой подписи или конфликте пакета, **не удаляйте установленный клиент без резервной копии**.

Приложение не распространяется через Google Play. Прежде чем устанавливать APK, убедитесь, что доверяете источнику файла.

## О проекте

VTLite Reborn — **неофициальный экспериментальный проект**, продолжающий работу с историческим клиентом [VToasters Lite / VTLite](https://github.com/vtosters/lite), основанным на модифицированной версии клиента VK. Проект не является официальным приложением VK. Успешный запуск не гарантирован на каждом устройстве.

**Конфиденциальность:** не публикуйте в Issues скриншоты переписок, пароли, токены, файлы сохранённой авторизации, полные URL загрузчиков или персональные данные. Для сообщений об ошибках достаточно модели телефона, версии Android, номера сборки и краткого описания проблемы.

**Права на компоненты:** наличие исходников или APK в публичном доступе само по себе не означает разрешения на распространение стороннего кода и ресурсов. Перед распространением бинарника необходимо учитывать лицензии и права соответствующих правообладателей.

Разработка и диагностические материалы хранятся отдельно; здесь публикуются только предназначенные для пользователей сведения и выпуски.
