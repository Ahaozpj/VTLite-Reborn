## 🔧 Как развивается проект

Это публичный репозиторий **готовых пользовательских сборок и проверенных исходников изменений**, а не хранилище приватных материалов разработки. Для каждого нового проверенного релиза публикуются:

1. Установочный APK в **GitHub Release → Assets**.
2. **Changelog относительно непосредственно предыдущей сборки**, без вымышленных исправлений.
3. Проверенные функции, известные ошибки, `versionCode` и SHA-256.
4. Сохранённая предыдущая сборка для отката — без скрытой замены APK.
5. Проверенные исходники собственных изменений с инструкциями и контрольными суммами; ограничения полноты и прав на сторонний код обозначаются явно.

## 🐛 Ошибки и диагностические журналы

Если не открываются диалоги, не отправляются сообщения или фотографии, не работает вход или капча, воспользуйтесь **[пошаговой инструкцией по сбору логов](docs/LOGS.md)**. В ней указано, какие переключатели включить, как воспроизвести ошибку и где попытаться найти файл на Android.

**Не загружайте исходные журналы в открытые Issues или чаты:** они могут содержать токены, cookies и персональные данные. Передавайте только проверенные и обезличенные фрагменты по согласованному закрытому каналу. Если не уверены, что удалось скрыть секреты, отправляйте только описание, время и скриншот.

В будущих версиях планируется отдельная кнопка «Собрать диагностический отчёт» с безопасной подготовкой и отправкой только по выбору пользователя. **В CP309 отдельная кнопка безопасного отчёта по-прежнему не заявлена; передавайте только проверенные обезличенные материалы.**
