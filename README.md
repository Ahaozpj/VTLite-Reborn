## 🔧 Как развивается проект

Это репозиторий **готовых пользовательских сборок**, а не хранилище приватных материалов разработки. Для каждого нового проверенного релиза публикуются:

1. Установочный APK в **GitHub Release → Assets**.
2. **Changelog относительно непосредственно предыдущей сборки**, без вымышленных исправлений.
3. Проверенные функции, известные ошибки, `versionCode` и SHA-256.
4. Сохранённая предыдущая сборка для отката — без скрытой замены APK.

## ⚠️ Важная информация

VTLite Reborn — **неофициальный экспериментальный клиент VK**, вдохновлённый историческим проектом [VTLite / VToasters Lite](https://github.com/vtosters/lite). Он не связан с VK и не распространяется через Google Play. Установка — на ваш риск; убедитесь, что доверяете источнику и что распространение учитывает права на сторонние компоненты.

Никогда не публикуйте пароли, токены, экспорт сессий, приватные ключи или содержимое переписок в Issues. В отчётах об ошибках указывайте модель телефона, версию Android, номер CP и этап воспроизведения.
