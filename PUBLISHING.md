### Осталось сделать владельцу

1. **До публичного распространения** проверьте, что лицензии и разрешения на распространение модифицированного приложения и сторонних компонентов это допускают.
2. Скачайте из своего Google Drive известную рабочую CP205, если файла нет на телефоне: [CP205 в личном Google Drive](https://drive.google.com/file/d/1fTTW9bL1-UgjQK5lLrOJlyXrYwTASW-K/view?usp=drivesdk).
3. Откройте черновик релиза по ссылке выше и нажмите **Edit**. На телефоне при необходимости включите «Версия для ПК» в браузере GitHub.
4. Перейдите к **Assets / Attach binaries**, выберите файл `VTLite_Reborn_CP205_SameSigner_Update_v4850.apk`.
5. Подтвердите имя, размер **78 522 511 байт** и SHA-256 **`e08a783a97a2a36bcfc86681750074b6b2ec9442cf0be3b593f0dc1eae3c0534`**. Если файл отличается, не размещайте его под этим именем и контрольной суммой.
6. Убедитесь, что ключ `.p12`, пароль, токены, архивы внутренней разработки и содержимое переписок **не прикреплены**.
7. Нажмите **Publish release**, оставив пометку **Pre-release**, пока тесты ограничиваются одним телефоном.

После публикации **проверьте в приватном окне браузера без входа в GitHub**, что файл можно скачать из Assets. Только после этого отправляйте другу публичную ссылку:

https://github.com/Ahaozpj/VTLite-Reborn/releases/tag/v4850-cp205

Прямая ссылка на APK **не работает до публикации вложения**:

https://github.com/Ahaozpj/VTLite-Reborn/releases/download/v4850-cp205/VTLite_Reborn_CP205_SameSigner_Update_v4850.apk

Для новых APK создавайте отдельные выпуски. **Никогда не заменяйте проверенную CP205 молча другим бинарным файлом** — она наша эталонная откатная сборка.

**Ограничение доступных ChatGPT-инструментов:** GitHub-коннектор не поддерживает загрузку APK как Release asset. GitHub Actions создал только черновик, чтобы сократить работу вручную.

## Контроль качества

- Не публиковать APK, если невозможно подтвердить SHA-256 и подпись.
- В публичном README описывать только реальные пользовательские тесты.
- Не считать успешную авторизацию на одном устройстве гарантией работы на новом аккаунте.
- Соблюдать права на сторонние компоненты.
