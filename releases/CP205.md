# 🚀 CP205 — первая проверенная сборка VTLite Reborn

**Дата:** 18 ноября 2026 · **Канал:** предварительный выпуск (pre-release)

> Впервые в наших тестах обычный вход **по логину и паролю** завершился успешно, без восстановления авторизации из файла. Проверено на одном устройстве; результат может отличаться на других аккаунтах.

## ✨ Что изменилось относительно CP182

| Компонент | CP182 | CP205 |
| :--- | :--- | :--- |
| Android `versionCode` | `4840` | **`4850`** |
| Подпись обновления | экспериментальная линия | **подписано совместимым сертификатом Reborn** |
| Код авторизации | исходная логика CP182 | **без изменений** |
| Практический результат входа | ранее наблюдался `BRUTEFORCE_LOCK` | **вход логином и паролем подтверждён** |

**Важно:** результат входа улучшился в практической проверке, но новый код входа в CP205 **не добавлялся**. Причина прошлой серверной ошибки пока не установлена. Это не гарантия авторизации у всех.
