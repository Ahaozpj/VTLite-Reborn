### Подтверждено пользователем

На RedMagic 8S Pro (Android 15) выполнены вход по логину и паролю, открытие личных переписок, отправка сообщений и медиа. После закрытия и повторного запуска приложения авторизация сохранилась.

### Ограничения

- Это практический результат на одном устройстве и одном аккаунте, **не** доказательство одинакового результата у всех пользователей.
- В CP205 изменён `versionCode` поверх CP182 и использована совместимая подпись. **Код авторизации не менялся**; почему ранее возникал `BRUTEFORCE_LOCK`, не выяснено.
- Редкие сбои `4603` при интенсивной загрузке фото могут сохраняться.
- Подпись была проверена для Android API 26, 28, 35 и 36, но это не равносильно проверке установки и входа на всех устройствах.

### Установка

Скачать файл `.apk` из **Assets** соответствующего GitHub Release. Архивы `Source code` не содержат установочный APK. Если Android показывает конфликт подписи с уже установленной другой сборкой, не удаляйте приложение без сохранения собственных данных.
