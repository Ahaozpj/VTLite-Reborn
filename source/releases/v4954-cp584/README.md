## Сборка изменений

Требуются Python 3, Java и smali/baksmali 3.0.10, а также законно полученная точная базовая сборка CP579 v4953. Базовая сборка и сторонние компоненты в этом комплекте не предоставляются. Декомпилируйте только `classes3.dex` базы через baksmali, замените две указанные классы, соберите полный DEX smali и проверьте приведённый SHA-256. Затем выполните `python build/package584.py BASE.apk classes3.dex OUTPUT_UNSIGNED.apk` из отдельного рабочего каталога (создаётся pack.json). Скрипт требует точных хешей входных файлов. Если сборка DEX не воспроизвела хеш, скрипт её отклонит. Полная независимая сборка из этого комплекта не подтверждена. Для самостоятельной установки подпишите APK собственным тестовым ключом: он не совместим с обновлением официально выпущенной Reborn. Приватный ключ релиза не публикуется.

Исходный исторический проект: https://github.com/vtosters/lite. Неофициальная модификация, не связанная с VK.
