# CP584 — восстановленные дельты конфиденциальности, тем и обработки ошибок

Частичное дополнение к накопленному комплекту v4954. Содержимое восстановлено сравнением точных оригинальной и релизной APK, а не заявлено как исторические авторские файлы. Включены только собственные новые строки и ссылки на строки локального оригинала; исходные тела унаследованных классов не распространяются.

- `LoggingInterceptor`: принудительный уровень NONE для старого HTTP-логирования.
- `EnterLoginPasswordPresenter`: удаление старого пути сохранения состояния учётных данных и инициализация счётчиков диагностики.
- `MsgSendUncheckedJob`: передача исключения в обработчик ошибки отправки и повторный выброс (не подавление исключения).
- `CookieHelper`: исправление формата двух адресов cookie.
- `ThemesUtils`: чтение настроек темы через специальный accessor и проверка Android API >= 31 для Monet.
- `TimeUtils`: удаление отладочной метаинформации, без выявленных содержательных изменений инструкций.

## Применение

Используйте собственную законно полученную точную исходную APK и baksmali 3.0.10. Декодируйте DEX в отдельные каталоги `classes`, `classes2`, ... `classes7` внутри общего каталога `DECODED`. Сценарий принимает только точные входные хеши и создаёт новый каталог с шестью классами, не изменяя оригинальные файлы:

```sh
python3 patches/replay_reviewed_classes.py ORIGINAL.apk DECODED OUTPUT
```

Это не самостоятельная сборка APK: дополнительные модули и ресурсы пока не восстановлены полностью; поведение на ART/реальном Android в этом этапе не проверялось. Не устанавливать отдельный DEX. В прежней классификации 167 классов `TimeUtils` был включён по различиям метаданных; здесь он отдельно помечен как метаданные, а не функциональное исправление.
