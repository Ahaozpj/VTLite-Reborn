# v4954 — восстановленные изменения пакета и конфиденциальности

Частичный накопленный комплект. Не полный исходный код приложения и не самостоятельная сборка.

## Восстановление патчей

База: оригинальный VTLite, SHA-256 `2c312fecefce700bae0a956227f79474a6e17da64e93f22f0cb98d4e0436bb30`. Целевой APK: v4954-cp584, SHA-256 `5f6f67d33141e398e97f951f68a83fa35d1c02bedf99a2e31f2bb714b521a3a8`.

Получите оригинальную базу законным способом. Извлеките DEX и декодируйте их baksmali 3.0.10 в каталоги `classes`, `classes2`, ..., `classes7`. Сценарии принимают точный оригинальный APK, корень декодированных классов и **новый** каталог вывода. Например:

```sh
python patches/patch_package.py original.apk decoded original_package_delta
python patches/patch_privacy.py original.apk decoded original_privacy_delta
```

Не требуется размещать оригинальные классы в публичном репозитории. Сценарии проверяют SHA-256 APK и каждого входного и выходного класса. Это лишь отдельные изменения, не полная сборочная цепочка.

- `patch_package.py`: 85 классов, 103 замены литералов имени пакета. В шести классах также удалена отладочная разметка `.line`; остальные 79 сохраняют её.
- `patch_privacy.py`: пять классов; защита строкового представления учётных данных, отключение старого логирования и старого механизма сохранения пароля Smart Lock. Это реконструкция поведения релиза, не новое изменение APK.
- Обе группы: независимое сравнение результатов с релизным Smali — 90/90; три отрицательных проверки на каждую группу отклонены до создания выходного каталога. Неверные APK, отсутствующий декодированный источник и неверный манифест отклонены.

## Исторические диагностические классы

Пять новых по отношению к оригиналу классов совпали с сохранёнными файлами передачи CP588 и с декодированным релизным DEX. Изолированная сборка smali 3.0.10 и повторное декодирование — 5/5 побайтовых совпадений. Не означает проверку работы авторизации на Android. Эти исторические модули не являются новой кнопкой сбора логов CP602 и не гарантируют безопасность всех мест вызова.

- `cp130/AuthFailureLabel`: классификатор ошибок входа.
- `cp134/TrustStateDialog`: наличие локального состояния доверия без вывода значения.
- `cp136/AuthCounter`: счётчик запросов.
- `cp140/OAuthShape`: категории узлов и имена параметров, не их значения.
- `org/vtlite/reborn/authtrace/RebornAuthDiag`: счётчики событий.
